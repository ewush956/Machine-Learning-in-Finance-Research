What you are seeing: Each point is a rolling 21-day estimate of annualized volatility (x-axis) and annualized excess return (y-axis).

Sharpe connection: Sharpe ratio is the slope of return versus risk. The dashed guide line uses the full-sample Sharpe ratio to show that tradeoff visually.

How to use it: Points higher for the same risk level represent better risk-adjusted outcomes. Points below zero on the y-axis indicate periods with negative excess return.
