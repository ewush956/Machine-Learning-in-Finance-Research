What you are seeing: Daily excess returns, which are daily stock returns minus an estimated daily risk-free rate.

What the shaded band means: The band shows one standard deviation above and below the average excess return. It represents the typical day-to-day range used in Sharpe calculations.

How to interpret it: A higher average excess return and a tighter spread generally support a higher Sharpe ratio. Wide swings with little average excess return lower the Sharpe ratio.
