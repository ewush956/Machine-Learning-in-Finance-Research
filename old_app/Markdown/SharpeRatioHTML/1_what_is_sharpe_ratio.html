Definition

Sharpe ratio measures how much return an investment earns after subtracting the risk-free rate, for each unit of volatility. 

S = (E[Rₚ - Rf]) / σₚ
  • Rₚ = portfolio/asset return
  • Rf = risk-free rate
  • σₚ = standard deviation of returns (volatility)

Why it is useful

  • Raw return alone can hide risk.
  • Sharpe ratio standardizes performance by risk.
  • It makes two strategies easier to compare on equal footing.

Finance note

In practice, we estimate Sharpe using sample means and standard deviations from historical daily returns. This dashboard annualizes the ratio with √252 (about 252 trading days per year).
