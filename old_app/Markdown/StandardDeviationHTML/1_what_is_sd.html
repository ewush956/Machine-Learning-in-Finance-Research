Definition

Standard deviation tells you how "spread out" numbers usually are from their average. If the standard deviation is small, most values hug the mean. If it's large, values wander farther away.

Definition Mathematical

It's the square root of the average squared distance from the mean. In symbols (sample standard deviation): 

s = sqrt( (1 / (n - 1)) * Σ (xᵢ - x̄)² )
  • x̄ = mean (average)
  • n - 1 is used for a sample (common in real datasets)

Key intuition

  • It is measured in the same units as the data.
  • It's a "typical distance from average," not a max/min.
  • Outliers can inflate it (because squaring makes big deviations explode).

Finance note: use returns, not prices

In investing, standard deviation is usually applied to returns (daily % changes), not raw prices. Prices trend upward over time; returns are more “stationary” and comparable.

This dashboard computes daily log returns: 

rₜ = ln(Cₜ / Cₜ₋₁)

Log returns are nice because they add over time and behave better in many models.
